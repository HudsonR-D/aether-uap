# Contributing to AETHER

Thank you for your interest in AETHER! We’re building the most capable open-source UAP detection agent in existence, and we need your help.

## How to Contribute

### 1. Reporting Bugs or Suggesting Features
- Use the GitHub issue templates
- Be as detailed as possible (logs, screenshots, hardware, expected vs actual behavior)

### 2. Code Contributions
1. Fork the repo
2. Create a feature branch (`git checkout -b feature/amazing-new-thing`)
3. Make your changes
4. Ensure tests pass and code follows style guidelines
5. Submit a Pull Request

### 3. Areas We Especially Need Help With
- Perception models (fine-tuning YOLO/RT-DETR on sky data)
- Agentic reasoning prompts & tool calling
- Hardware testing (Jetson, Raspberry Pi, various cameras)
- Documentation & tutorials
- Multi-station coordination logic
- UI/UX for the dashboard

## Code Style
- Python: Black + Ruff
- Documentation: Clear, example-rich Markdown
- Commits: Conventional Commits style

## Code of Conduct
Be respectful, collaborative, and focused on scientific truth-seeking.  
No conspiracy theories, no gatekeeping, no drama.

## Questions?
Open a discussion or reach out via GitHub Issues.
