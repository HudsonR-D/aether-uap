**Enter AETHER**

AETHER is an **open-source, self-improving agent** that turns *any camera or video stream* into a scientific-grade UAP detection system.

Here’s what it does:

- Plugs into **any camera** (RTSP, USB, drone feeds, YouTube, etc.)
- Runs real-time anomaly detection with very low false positives
- Captures **crisp, enhanced, metadata-rich evidence** when something interesting happens
- **Improves itself over time** using real-world data (with full user consent and privacy controls)

It has a Meta-Agent that constantly proposes improvements, tests them in a safe sandbox, and only promotes changes that actually make the system better — with automatic checkpoints and rollback.

This is one of the first open-source scientific instruments designed to *get smarter every week*.

**Want even more power?** (Optional but recommended)

Add your Gemini API key for the full reasoning agent:

```bash
# Create a .env file (never commit this)
echo "GEMINI_API_KEY=your_key_here" > .env
```

**Safety note**: Never share your API keys. The system is designed to work great even without them (using local models), but Gemini unlocks significantly better reasoning and justification.
